# PowerApps CRM Example

Esta carpeta contiene una guía para construir un CRM básico en Power Apps que maneje oportunidades de ventas y tareas. Incluye la descripción de la estructura de datos, fórmulas de ejemplo y la lógica de los flujos de Power Automate necesarios para notificaciones.

> **Nota:** Power Apps guarda las aplicaciones en archivos `.msapp` que se generan desde el portal de Power Apps. Debido a las limitaciones del entorno, este repositorio solo contiene instrucciones y ejemplos de fórmulas. Para tener un archivo `.msapp` listo para importar, deberá crear la aplicación siguiendo estas instrucciones y luego exportarla desde Power Apps.
